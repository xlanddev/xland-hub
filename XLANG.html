System Requirements

Check the requirements before installing XLANG.

Operating System Windows 10 / 11 (64-bit)
Interpreter No GCC required
Virtual Machine No GCC required
Native Compilation GCC or Clang required
Recommended Compiler MSYS2 UCRT64 GCC
Important: GCC or Clang is only required for Native Compilation. XLANG Interpreter and Virtual Machine can still be used without installing a C compiler.
