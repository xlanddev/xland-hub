📚 XLAND KNOWLEDGE BASE

سوالات متداول

قبل از ارسال Ticket شاید پاسخ سوالت همین‌جا باشد.

از بخش پشتیبانی نوع درخواست خود را انتخاب کنید، فرم را کامل کنید و روی «ارسال درخواست» بزنید. Ticket ID برای درخواست شما ساخته می‌شود.

Ticket ID یک شناسه یکتا برای درخواست شماست. با استفاده از آن می‌توان در آینده درخواست را از طریق Xland API پیگیری کرد.

Open یعنی درخواست تازه ثبت شده، Pending یعنی درخواست در حال بررسی است، و Solved یعنی درخواست حل شده است.

در نسخه 5.1 درخواست‌ها فعلاً به صورت موقت داخل localStorage مرورگر ذخیره می‌شوند. در نسخه Backend، این سیستم به Xland API متصل خواهد شد.

بله. از بخش Ticket Center می‌توانی درخواست‌های ذخیره‌شده در همین مرورگر را مشاهده کنی.

معماری نسخه 5.1 برای اتصال به Backend آماده شده، اما ذخیره‌سازی فعلی Frontend و localStorage است.
